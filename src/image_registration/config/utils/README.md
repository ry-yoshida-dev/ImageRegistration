# utils

## Overview

Mapping of each `RegistrationMethod` to its parameter class and `ConfigKey`.

## Components

| Component | Description |
| --------- | ----------- |
| [`method_with_key.py`](./method_with_key.py) | `MethodWithKey`: a parameter class paired with its config key |
| [`key_name_resolver.py`](./key_name_resolver.py) | `KeyNameResolver`: resolves a `RegistrationMethod` to its `MethodWithKey` |
