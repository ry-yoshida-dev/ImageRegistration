# processors

## Overview

Image registration implementations, one sub-package per method.

## Components

| Component | Description |

| [`kp_matching/`](./kp_matching/README.md) | Keypoint detection and matching registration |

| [`farneback/`](./farneback/README.md) | Farneback dense optical flow registration |
